**Кейс по анализу трафика используемых приложений**
```date_id```: дата.

```option_name```: название приложения (есть пропущенные).

```bytes_in```: объём входящего трафика.

```bytes_out```: объём исходящего трафика.

```account_id```: идентификатор аккаунта.

```option_datetime```: время последнего использования приложения 

*будьте внимательны к пробелам в числовых полях* - это реальные данные, выгруженные из БД без специальной подготовки
