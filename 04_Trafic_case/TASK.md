Привет!

Мы получили выгрузку по мобильному трафику абонентов за сентябрь
(data_traffic.csv). Нужно разобрать её и подготовить пакет отчётов
для руководства и профильных подразделений. Ниже — что именно требуется,
в каком формате и к какому сроку.

Формат: Excel-файл, один отчёт — один лист. Каждый лист с шапкой,
периодом, источником данных и датой подготовки.

--------------------------------------------------------------------------------
СТРУКТУРА ДАННЫХ (для контекста)
--------------------------------------------------------------------------------
date_id          - дата агрегации
option_name      - название приложения (возможны пропуски)
bytes_in         - объём входящего трафика
bytes_out        - объём исходящего трафика
account_id       - идентификатор аккаунта
option_datetime  - время последнего использования приложения

--------------------------------------------------------------------------------
ЗАДАЧА 1. ОБЩИЙ ОБЗОР ТРАФИКА
--------------------------------------------------------------------------------
Лист: "Overview"

Что нужно:
  - Общий трафик за период (в ГБ и ТБ)
  - Входящий / исходящий трафик отдельно
  - Соотношение in/out
  - Количество сессий
  - Количество уникальных аккаунтов
  - Количество уникальных приложений
  - Средний и медианный трафик на сессию
  - Минимальная и максимальная дата в данных

Формат: KPI-плитки сверху + краткий текстовый вывод (3-5 предложений).
Срок: пятница, 18:00.

--------------------------------------------------------------------------------
ЗАДАЧА 2. ТОП-20 ПРИЛОЖЕНИЙ ПО ТРАФИКУ
--------------------------------------------------------------------------------
Лист: "Top_Apps"

Что нужно:
  - Рейтинг топ-20 приложений по суммарному трафику
  - Доля каждого приложения в общем трафике, %
  - Количество сессий
  - Средний трафик на сессию
  - Число уникальных аккаунтов
  - Профиль in/out (соотношение скачивания к отдаче)

Дополнительно:
  - Отдельно выделить приложения с долей скачивания > 90%
    (это стриминг/просмотр контента) и < 50% (это отдача, P2P, мессенджеры).
  - Отдельно посчитать долю строк с пустым option_name —
    это критично, скажи сколько процентов трафика мы "не видим".

Визуализация: горизонтальная гистограмма топ-10.
--------------------------------------------------------------------------------
ЗАДАЧА 3. ПРОФИЛЬ АККАУНТОВ
--------------------------------------------------------------------------------
Лист: "Accounts"

Что нужно:
  - Топ-100 аккаунтов по суммарному трафику
  - Средний трафик на аккаунт
  - Количество сессий на аккаунт
  - Средний трафик на сессию
  - Число уникальных приложений на аккаунт
  - Количество дней активности (по date_id)

Дополнительно:
  - ABC-анализ аккаунтов: группа A (80% трафика), B (15%), C (5%).
    Сколько аккаунтов попало в A? Это наши "тяжёлые" пользователи.
  - Отдельно выделить аккаунты с аномально высоким средним трафиком
    (> среднее + 3 сигмы) — подозрение на корпоративное
    или шарящее использование.
--------------------------------------------------------------------------------
ЗАДАЧА 4. СУТОЧНЫЙ И НЕДЕЛЬНЫЙ ПРОФИЛЬ
--------------------------------------------------------------------------------
Лист: "Time_Profile"

Что нужно:
  - Трафик по часам суток (0-23): сумма total_bytes
  - Трафик по дням недели (Пн-Вс): сумма total_bytes
  - Сравнение будни vs выходные (средний трафик на день)
  - Пиковые часы и дни
  - Топ-5 приложений в пиковые часы

Дополнительно:
  - Построить линейный график по часам.
  - Построить столбчатую диаграмму по дням недели.

Визуализация: 2 графика + таблица.

--------------------------------------------------------------------------------
ЗАДАЧА 5. КАЧЕСТВО ДАННЫХ (DATA QUALITY)
--------------------------------------------------------------------------------
Лист: "DQ_Report"

Что нужно:
  - Доля строк с пустым option_name
  - Доля строк с пустым account_id
  - Доля строк с нулевым трафиком (bytes_in=0 И bytes_out=0)
  - Доля аномальных записей, где option_datetime < date_id
  - Количество полных дубликатов
  - Диапазон дат по date_id и option_datetime

Формат: таблица с метриками + текстовая оценка пригодности данных
(например: "данные пригодны для анализа, кроме 40% строк
с неопознанным приложением").

--------------------------------------------------------------------------------
ЗАДАЧА 6. АНОМАЛИИ
--------------------------------------------------------------------------------
Лист: "Anomalies"

Что нужно:
  - Топ-20 самых крупных сессий по total_bytes
  - Сессии с перекосом in/out > 100 (сильная асимметрия)
  - Сессии с нулевым трафиком
  - Аккаунты с трафиком > среднее + 3σ
  - Записи, где option_datetime < date_id

Формат: таблица с указанием account_id, option_name, option_datetime,
total_bytes и кратким комментарием аналитика (почему это аномалия).

--------------------------------------------------------------------------------
ЗАДАЧА 7. СВОДНЫЙ ДАШБОРД ДЛЯ РУКОВОДСТВА
--------------------------------------------------------------------------------
Лист: "Dashboard"

Что нужно:
  KPI-плитки:
    - Общий трафик, ТБ
    - Уникальных аккаунтов
    - Уникальных приложений
    - Средний трафик на сессию
    - Доля неопознанного трафика

  Графики:
    - Топ-10 приложений (горизонтальная гистограмма)
    - Трафик по часам (линия)
    - Категории трафика (кольцевая диаграмма)
    - Динамика по дням (линия с трендом)

  Срезы (Slicers):
    - По категории приложения
    - По дню недели

Формат: один лист A4, читается без пояснений.

--------------------------------------------------------------------------------
ЗАДАЧА 8. АНАЛИТИЧЕСКАЯ ЗАПИСКА
--------------------------------------------------------------------------------
Лист: "Summary"

Что нужно (не более 1 страницы):
  1. Ключевые выводы (5 пунктов):
     - Топ-приложения и их доля
     - Пиковые часы и дни
     - Сегментация аккаунтов
     - Доля неопознанного трафика
     - Обнаруженные аномалии

  2. Гипотезы и рекомендации (3-5 пунктов):
     - Что делать с пустым option_name (например, "исправить DPI")
     - Как использовать топ-аккаунты (тарифы, предложения)
     - Как использовать пиковые часы (таргетинг, capacity)

Формат: текст + 1-2 ключевых графика. Без "воды", только факты и цифры.

--------------------------------------------------------------------------------
ОБЩИЕ ТРЕБОВАНИЯ
--------------------------------------------------------------------------------
- Все файлы в кодировке, которая корректно отображает русские символы
  (Windows-1251 или UTF-8 с BOM).
- На каждом листе: шапка с названием отчёта, периодом, источником,
  датой подготовки.
- Числа форматировать с разделителями разрядов.
- Проценты — с одним знаком после запятой.
- Объёмные числа — в удобных единицах (КБ / МБ / ГБ / ТБ).
- Никаких "сырых" выгрузок без агрегации.

--------------------------------------------------------------------------------
ЧТО НЕ НУЖНО
--------------------------------------------------------------------------------
- Не нужно присылать промежуточные версии.
- Не нужно делать 20 листов "на всякий случай".
- Не нужно пересказывать данные словами без цифр.
- Если чего-то не хватает в данных — напиши в сопроводительном письме,
  не додумывай.

--------------------------------------------------------------------------------
СДАЧА РАБОТЫ
--------------------------------------------------------------------------------
Один Excel-файл: traffic_report_<дата>.xlsx
Листы в порядке: Overview, Top_Apps, Accounts, Time_Profile,
DQ_Report, Anomalies, Dashboard, Summary.

Плюс сопроводительное письмо в теле ответа:
  - Что сделано
  - Какие выводы
  - Какие вопросы остались
  - Что рекомендуется сделать дальше

Вопросы — в чат, не по телефону.
